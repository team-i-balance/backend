# S등급 변환 루프: 로컬 평가

2026-11-05, 로컬 AEGIS ONNX 모델과 현재 규칙, CPU 2스레드로 기존 합성·공개 평가 데이터 600문장을 실행했다. 입력은 Python socket 차단 하에서 처리했으며 네이티브 라이브러리의 모든 통신 여부를 검증한 것은 아니다.

|---|---:|---:|---:|---:|---:|

`checked`는 탐지기가 변환문에서 더 이상 항목을 보고하지 않았다는 뜻이다. 위험이 없거나 전송해도 안전하다는 뜻은 아니다. `blocked`는 탐지된 기밀 유형 기준이며 실제 기밀 여부를 판정한 수치는 아니다.

## 정답 원문 잔존 점검

각 `checked` 문서에서 라벨된 정답 원문 문자열이 변환 결과의 어디에든 그대로 포함되는지 별도 검사했다. 라벨이 있는 한국어 문서 427건 중 25건, 라벨이 있는 비밀정보 문서 9건 중 6건에 정답 문자열이 남았다. 비밀정보 잔존 6건은 API 키와 비밀번호 각각 3건이다. 같은 문자열이 문서에 여러 번 나올 수 있어 이 검사는 위치별 잔존률이 아니며, 일부는 과대 계수할 수 있다. 반대로 정답 라벨 자체가 빠진 정보나 일부만 남은 원문은 이 지표만으로 포착하지 못한다.

이 결과는 재검사 자체가 탐지 누락을 보완하지 못하는 사례가 있다는 뜻이다. 따라서 `checked`를 외부 전송 승인으로 사용하면 안 된다. `review`/`blocked` 문서는 변환 결과가 반환되지 않거나 사용자 검토가 필요해 위 잔존 점검 대상에서 제외했다.

합성 단위 테스트에서는 재검사 후 다음 회차 치환, ISO 생년월일 일반화와 강화, 삭제·복원 분리, 기밀 차단, 충돌·반복 한도·검사 실패를 확인했다. 준식별자 조합을 통한 실제 재식별 위험 평가는 구현하지 않았으며, 독립 음성셋 및 실제 업무 데이터 검증이 필요하다. 비밀정보 표본은 CC BY-NC 4.0 표기 자료다.

## 기존 1회 처리와 동일 문장 대조

동일한 모델과 문장에 기존 `LocalSession`과 반복 루프를 각각 적용했다. 두 방식 모두 결과를 반환했고 정답 주석이 있는 문장만 비교했다. 정답 원문 문자열이 변환 결과에 그대로 남은 문서는 한국어 427건에서 **45→25건**, 비밀정보 9건에서 **7→6건**이었다. 새 루프의 `blocked`·`review`는 이 비교에서 제외했다.

한국어 결과 반환 문장 456건에서 1회 처리와 반복 루프의 처리시간은 각각 중앙값 77.78→84.00ms, p95 151.29→238.12ms였다. 이 대조는 전체 정답 문자열 잔존 여부만 세므로 부분 노출이나 모든 오탐을 측정하지 않는다. 반복 검사는 탐지기가 계속 놓치는 정보를 보장해서 찾지 못하며, `checked`도 전송 승인이 아니다.
